# Java Class Diagram Generator (クラス図自動生成・編集ツール)

指定したフォルダ内のJavaソースコードを解析し、クラス図を自動生成するデスクトップアプリケーションです。生成後のクラス図は、直感的なマウス操作でレイアウトを自由に編集・調整できます。

## 概要
オブジェクト指向言語の設計書として欠かせないクラス図を、既存のコードから瞬時にリバースエンジニアリングします。
単に描画するだけでなく、開発者が「見やすい配置」に手動で微調整できる柔軟性を備えています。

- **主な対象ユーザー:** Java開発者、オブジェクト指向設計を学ぶ学習者

## 🌟 主な機能と操作方法

### 1. クラス構造・関係性の自動分析
- **コード解析:** 指定フォルダ内の全 `.java` ファイルを読み込み、クラス名、フィールド、メソッドを抽出。
- **関係性と多重度の特定:** クラス間の「依存」「継承」「実現」「集約」などの関係と、その多重度（1対多など）を自動で分析し、クラス図として描画します。

### 2. インタラクティブなレイアウト編集機能
生成されたクラス図の重なりや配置を、以下のマウス操作で自由に変更できます。

| 操作対象 | マウスアクション | 動作・効果 |
| --- | --- | --- |
| **クラスボックス** | ドラッグ & ドロップ | ボックスを任意の位置に移動 |
| **関係を示す矢印** | 線上をクリック | 中継点（ポイント）を追加 |
| **矢印の中継点** | ドラッグアンドドロップ | 中継点の位置を変えて矢印を折れ矢印へ変形 |
| **矢印の中継点** | マウスホバー + 右クリック | 追加した中継点を削除 |

### 3. 画像エクスポート機能
- 画面の何もない場所（背景）を**右クリック**するとコンテキストメニューが表示され、編集後のクラス図を **PNG形式の画像ファイル**として保存できます。

## 💡 こだわったポイント・技術的工夫

### 1. 構文解析（パーサー）の自作と抽象化
外部の重いライブラリに頼らず、Javaファイルの文字列からクラス構造を抽出するロジックを実装しました。正規表現や字句解析の工夫により、クラス間の参照関係や多重度を正確に判定するアルゴリズムを構築しました。

### 2. Swingによる高度なグラフィック処理とイベントハンドリング
クラスボックスや矢印、および動的に追加される「中継点」の座標管理を徹底しました。`MouseListener` や `MouseMotionListener` を駆使し、ドラッグ時の再描画（`repaint()`）を最適化することで、カクつきのない滑らかな操作感（折れ線矢印の変形など）を実現しました。
